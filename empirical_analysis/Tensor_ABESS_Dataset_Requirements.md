# Tensor-ABESS 实证数据需求简表

版本：2026-10-26｜适用算法：冻结的 v5.2-search-final＋原MSIC

## 1. 我们需要验证什么

寻找有科学依据的真实回归问题，检验三模式变量选择是否带来预测、模型简洁性或支撑稳定性的实际价值。不是寻找能保证ABESS排名第一的数据。预测精度、稀疏性、稳定性和成本应分别评价；北京实证目前尚未证明优于主要竞争方法。

## 2. 必须满足的条件

| 项目 | 要求 |
|---|---|
| 输入结构 | 每个评价样本对应 X∈R^(p1×p2×p3)。三个模式有固定、可比较的物理或实验含义；不得把普通表格任意reshape成三维。数据整体通常为 n×p1×p2×p3，样本轴不计入三个特征模式。 |
| 响应变量 | 有真实观测的数值型标量y，优先浓度、容量、力、速度等连续测量；不能把类别编码当连续响应，不能用同一输入的确定性运算制造“真实标签”。 |
| 结构依据 | 有理由假设少量模式坐标能共同提供主要信息，即 supp(B)⊆S1×S2×S3。支撑不必连续，块内不要求全部非零；局部信号、低秩、自然三维均不自动等于矩形稀疏。 |
| 样本身份 | 明确实体ID、重复测量、批次/日期/工况。分清记录数、独立实体数和独立组数；窗口、像素、循环不能冒充独立实体。 |
| 数据可得 | 官方或作者来源可下载，有可读格式、字段说明、标签映射、使用条款及原始文件完整性检查。不能只有代码或论文而拿不到真实标签。 |
| 公平评价 | 全部方法使用一致样本与主输入；分组/时间划分符合问题，预处理和调参只使用训练数据。保留强简单基线与真正未用于选择方案的测试部分。 |

## 3. 优先特质与警示

优先：数百个独立实体或明确的重复实验；坐标对齐；标签有足够变化；输入与响应有直接科学联系；存在超越均值或简单历史量的预测信息；张量经固定降采样后可在现有计算预算内处理。

建议优先审查约200—500及以上独立实体，但这只是资源与研究目标上的偏好，不是理论门槛。只有几十个实体的数据并非不能用，必须按实体分组评价并限制结论。还须核查训练折caps是否允许拟研究的模型形状，不为新数据改caps或MSIC。

警示：响应变化几乎只来自文件/批次；样本位置无法对应；输入包含由目标计算的健康指标；同一实体跨训练/测试；依靠未来插值；全样本筛选波段；大量缺失没有来源解释。出现这些问题，先审计，不立刻跑完整ABESS。

## 4. 最小筛选流程与停止规则

来源和结构核验 → 小规模身份/标签审计 → 不含ABESS排名的简单基线预检 → 冻结输入、目标、划分及评价 → 一次正式方法比较。

方法优势必须用同输入下的预测、实际非零数/模式支撑、稳定性与成本共同检查。若比较等复杂度模型，复杂度与容许误差只在训练内部确定；不能以最终测试排名决定保留哪个数据。真实数据无已知B时，不报告Exact或“恢复了真支撑”。

每个候选先提交一页数据卡：来源/版本与下载量、样本实体和分组、X三轴、y与单位、完整性/泄漏风险、结构假设、验证方案、继续或停止理由。保留全部已测候选与负面结果；新数据未胜出不自动触发算法修改。

依据：用户已提供的原版算法说明及Apple、Mushroom、北京空气质量最终报告。以上是项目筛选规范；样本量偏好与执行顺序是本轮建议，不是已有统计保证。
