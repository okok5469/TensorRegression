# Tensor-ABESS近期工作报告

## 主要结论

近期工作主要完成了算法正确性修复、模拟结果复查，以及LEMON、Apple、Mushroom和北京空气质量四套真实数据的实证比较。正式版本确定为 **v5.2-search-final，继续使用原MSIC**。它修复了搜索过程中“找到了较好模型，却未必返回该模型”的问题，并补全原预算内应检查的模型尺寸；这些改动提高了实现可靠性，但没有带来所有场景预测误差的一致改善。

**当前四套数据均未展示足够的比较优势，暂不将其中任何一套作为论文主实证。** LEMON未超过仅协变量，Apple整体信号弱，Mushroom弱于原平均谱对照且文件块泛化失败，北京虽能预测未来污染，但未超过强对照、也未证实多站增量。这是本次向老师汇报的定位调整，不改写旧封存报告、实验数值或算法版本。

## 一、算法究竟改了什么

张量回归把输入保留为三个有含义的轴。模型分别选择各轴的一组位置，形成矩形支撑，再在其中估计系数。例如选4个站点、1种污染物和2个时间段，矩形容量为q=4×1×2=8。矩形不要求位置连续，也不保证其中每个系数严格非零。

从v5到正式v5.2，主要有三个改动点。

**第一，v5.1改为返回同一模型尺寸下访问过的最佳完整模型。** 旧版固定尺寸BCD可能返回最后一次状态，即使前面曾出现更好的状态。现在同步保存支撑位置、系数和训练误差，最终返回该固定尺寸迭代中训练误差最低的完整状态。可以用“固定尺寸下训练误差10→8→9”理解：应该带回误差8对应的完整方案，而不是最后的9。**这是解释用的玩具例子，不是实际实验轨迹；不同模型尺寸之间仍按原MSIC选择。**

**第二，v5.1区分探索与接受，并补齐运行保护。** 搜索允许暂时走到较差位置，保留原来从独立起点出发的探索机会；同时单独记录已接受的改善和访问过的最佳模型。加入数值异常、支撑合法性、重复状态和舍入误差检查，避免把循环或数值问题当作正常结果。不能把这项修复描述为“强制每一步误差下降”，也不能说它把独立起点（Cold）改成了热启动（Warm）。

**第三，v5.2补全合法模型尺寸。** 旧网格只检查少量尺寸。以某轴上限10为例，旧规则可能只检查1、4、6、8、9、10，漏掉2、3、5、7。现在检查各轴上限内、且满足总参数预算的全部正整数尺寸组合。**补全的是模型尺寸，不是穷举所有位置支撑；原有各轴上限和总预算没有扩大。** v5.1到正式v5.2的核心增量只涉及这一点。

评分仍可通俗理解为“训练误差＋复杂度代价”，即原MSIC；相近评分时偏向较小模型的容忍带也予以保留。**MSIC及该容忍带在v5已有，不是v5.2新发明。** 最终仍在矩形支撑内做OLS，没有改成Ridge。后续探索过FS小样本修正及Warm起点，但均未进入正式版：FS有预测收益，却损失部分恢复能力，未通过联合门槛；Warm仍是研究原型。

## 二、模拟结果：正确性改善不等于泛化必然改善

正式模拟以基准n=200、维度32×20×25、信噪比SNR=2、相关参数0.3为中心改变条件，每个标签50次，测试集500例。PMSE是测试预测均方误差，越低越好；Exact表示是否完整找回真实支撑，仅模拟中知道真支撑时才可计算。模拟还设了知道真实变量位置的Oracle OLS作为诊断参照，下面集中比较三种可部署方法。

按全部14个标签的700条记录加权，v5的平均PMSE为2.236761，v5.2为2.381274，**上升6.46%**；Exact计数则由138增至182。因此不能把升级概括为全面提升。另需注意：14个标签实际只有10种配置、600个唯一输入，并非14组彼此独立的验证。

为区分修复与补网格的作用，对五个场景做了同输入三版本配对：

| 场景，每组50次 | v5 PMSE | v5.1 PMSE | v5.2 PMSE |
|---|---:|---:|---:|
| 基准 | 1.990669 | 2.012130 | 2.012130 |
| 弱信号SNR=0.5 | 1.837097 | 1.926368 | 1.926368 |
| 小样本n=100 | 5.196560 | 6.442026 | 6.442026 |
| 较大样本n=400 | 1.297588 | 1.299304 | 1.189516 |
| 无相关rho=0 | 2.573943 | 2.948160 | 2.948160 |

n=400的Exact依次为1/50、1/50、49/50，改善主要来自尺寸网格补全；n=100的退化发生在BCD修复阶段，而非v5.2补网格阶段。更充分地降低训练误差，可能同时加重小样本过拟合。

n=100还有结构限制：原各轴上限为(4,4,4)，不能容纳真形状(4,3,5)，虽然真容量60没有超过总预算70。这一上限在v5.2没有修改，不能把所有恢复失败都归于MSIC。

下面列出与汇报幻灯片一致的六个代表场景。数值为50次PMSE的均值±样本标准差：

| 场景 | 正式ABESS | Vector Lasso | Tensor-GLasso |
|---|---:|---:|---:|
| 基准 | 2.01±0.68 | 2.87±0.25 | 3.02±0.58 |
| SNR=0.5 | 1.93±0.67 | 1.56±0.12 | 1.64±0.37 |
| n=100 | 6.44±1.57 | 3.04±0.22 | 3.10±0.23 |
| n=400 | 1.19±0.09 | 2.74±0.20 | 2.96±0.18 |
| 小维度16×12×15 | 1.81±0.60 | 2.71±0.20 | 2.89±0.43 |
| 大维度64×30×40 | 2.79±1.40 | 2.99±0.19 | 3.02±0.19 |

正式ABESS在14个标签中的11个标签上，平均PMSE同时低于本批Lasso和GLasso；未占优的是SNR=0.5、SNR=1和n=100。但旧基线实现存在收敛诊断限制，这一比较应限定为本批实现和实验，不能直接推广为算法普遍优越性。

## 三、四套真实数据：有预测信号不等于有方法优势

下表先看每套数据内部的R²和RMSE。R²越高越好，RMSE越低越好；**各任务响应和单位不同，RMSE不能跨行直接比较，R²也不是跨数据集难度排名。** LEMON、Apple和Mushroom主验证均先计算每次完整折外预测指标，再对三次重复求均值；北京是一次固定未来时段，Mushroom文件块结果则是拼合五个块外预测。

| 数据与评价口径 | 正式ABESS：R² / RMSE | 代表性较强对照：R² / RMSE | RMSE单位及判断 |
|---|---|---|---|
| LEMON，145人，3次重复×5折 | −0.597 / 0.5046 | 仅协变量：0.368 / 0.3175 | log(TMT_5)尺度；未体现EEG增量 |
| Apple，240记录，3次重复×5折 | 0.009 / 0.8383 | 展平张量Ridge：0.035 / 0.8270 | 干物质百分点；整体信号弱 |
| Mushroom，250记录，重复谱分组3×5折 | 0.786 / 13.6523 | 原平均谱Ridge：0.858 / 11.1252 | 干物质百分点；可预测但弱于简单对照 |
| Mushroom，五个文件留一块测试 | −0.158 / 31.7833 | 展平张量Ridge：−0.109 / 31.1006 | 干物质百分点；八方法整体R²均负 |
| 北京，未来一年352个日期 | 0.582 / 47.4525 | Vector Lasso：0.600 / 46.4079 | µg/m³；未超过强对照 |

![四套实证的比较结果](figures/empirical_comparison.png)

前三套数据的点为3次完整OOF指标均值，误差线为重复间样本标准差；重复使用相同实体，不是独立外部实验。北京仅有一次未来测试，不绘制重复标准差。图中对照按已有主评估RMSE最低者选择，仅作描述，不据此重新调参。

**LEMON：已有行为预测信息，尚未显示EEG张量的额外价值。** 输入为61通道×16时间窗×5频带，响应为log(TMT_5)，同时控制已有协变量。正式原MSIC的折外R²为负，弱于仅协变量，也弱于Ridge、Lasso和GLasso。研究性FS降低了原版本误差，但仍未超过仅协变量，且没有被采用为正式规则；不能拿FS成绩替换正式ABESS成绩。当前只可作为增量预测未获支持的边界案例。

**Apple：流程可靠，预测信息弱。** 三次重复五折下，ABESS平均R²约0.009，最好Ridge也仅约0.035。多数方法接近训练均值；ABESS有14/15折选q=1。它适合作为边界案例，不能因表现弱而改响应、ROI或正式选阶规则。

**Mushroom：随机验证有信号，文件块泛化差。** ABESS随机分组CV的RMSE为13.65个百分点、R²为0.786；原平均谱Ridge的RMSE为11.13。留一个原MAT文件作测试时，ABESS整体R²降至−0.158，八种方法的块外整体R²均负。最高干物质文件块的全部50条响应还超出训练响应上界。文件只代表存储分块，不能未经证据称为生物批次。这套数据保留为补充或分布变化边界案例。

![Mushroom两种验证协议的结果](figures/mushroom_protocol_comparison.png)

图中固定比较ABESS与原平均谱Ridge，观察同一方法在不同验证对象下的变化；主验证绘制重复均值及样本标准差，文件块结果为拼合评价、不绘制重复标准差。表中另列文件块协议下表现最好的展平张量Ridge，二者不可混为同一种Ridge输入。

## 四、北京空气质量：能预测未来，仍缺少比较优势

任务是在目标日开始时，预测Aotizhongxin站当天PM2.5平均浓度。输入来自自然前一天，构成 **12站点×6污染物×6个四小时区间** 的真实三阶张量。所有坐标固定，直接对应站点、污染物和历史时间段。

共1409个有效日期，开发阶段按时间回测，最后以2016-03至2017-02的352个共同日期检验未来预测。缺失值填补和标准化仅用当前训练期信息。测试期间模型固定，每天更新前一日已观测输入，不用测试标签重训；真实数据发布延迟未知，结果对应理想离线可用性假设。

未来一年结果如下，RMSE、MAE单位均为µg/m³：

| 方法 | RMSE | MAE | R² |
|---|---:|---:|---:|
| 历史训练均值 | 73.40 | 53.40 | −0.001 |
| Persistence | 68.75 | 46.33 | 0.122 |
| 单站Ridge | 47.47 | 33.25 | 0.581 |
| 完整张量Ridge | 46.81 | 32.33 | 0.593 |
| Vector Lasso | 46.41 | 32.78 | 0.600 |
| Tensor-GLasso | 46.42 | 32.28 | 0.600 |
| 正式Tensor-ABESS | 47.45 | 32.75 | 0.582 |

ABESS较Persistence降低RMSE约30.98%，12个月均有改善，说明存在实际未来预测价值。但Ridge、Lasso和GLasso也能明显改善Persistence；ABESS与单站Ridge仅差−0.0127µg/m³，误差比最好方法高约2.25%，**不能据此宣称多站增益或ABESS预测优越性，因此当前也不作为主实证。** 固定三模式和较少坐标可以描述模型结构，不能代替强对照上的实际优势。

未来模型选择5个站点、2种污染物和2个晚间时段，形成20/432个允许坐标。这个结果说明表示紧凑，但不等于完整统计自由度只有20，也不能解释为因果污染来源；它不足以弥补当前预测比较优势的缺口。

## 五、建议向老师强调的定位

目前四套实证都应完整保留，但均未提供足够的比较优势来承担论文主实证：LEMON尚未显示EEG增量，Apple信号弱，Mushroom简单平均谱更好且跨文件失效，北京未超过强对照。它们可用于汇报已经完成的验证、负面结果与方法适用边界，不能把“实验跑通”“优于均值或Persistence”直接当成“本方法有优势”。后续论文主张应与证据相称；模拟同时保留恢复收益和小样本风险。正式算法保持原MSIC，不根据数据成绩切换FS、Warm，也不通过删去不利实证重塑结论。本次只调整汇报定位，旧封存实验报告保持原样。
