## Definitions and limitations

- PMSE includes observation noise and uses 500 independent test records. It is not RMSE or signal MSE. PMSE was reaggregated from recorded per-task values; test X/y were not regenerated.
- REE = Frobenius norm(Bhat-Btrue) / Frobenius norm(Btrue), not squared; independently verified from saved arrays.
- TPR_m = intersection size / true support size.
- FPR_m = false selected mode coordinates / (p_m - true support size). Original CSV has no FPR: new FPR columns were derived directly from each NPZ support set. FPR is not FDR or 1-precision. True mode sizes are 4,3,5; denominators vary with dimensions.
- Lasso/GLasso mode support metrics use existing reported axis supports; rectangular envelope capacity is not their actual coefficient nonzero count.
- runtime_sec is each task method timer. Its sum is aggregate method time, not parallel cluster wall time. Oracle timing is not a deployable pipeline cost. Baseline convergence diagnostics remain limited; claims apply to these implementations.
- Deterministic reaggregation is not an additional scientific replicate. Pooled 700-row means retain repeated label weighting.
