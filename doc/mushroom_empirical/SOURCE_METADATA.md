# Mushroom 结构与来源核验

日期：2026-10-23。状态：结构与 ID 映射通过；此文不代表全部像素 QC 或模型实验完成。主线已逐文件验证全部官方 MD5，身份记录见 [raw_file_identity.json](raw_file_identity.json)。本次仅使用 whosmat 与选择性 loadmat，未构建缓存、未拟合。

[官方固定记录](https://zenodo.org/records/10302438)说明共250例，每 MAT 存50例及波长、标签。原始文件分别包含 M001–M050、M051–M100、M101–M150、M151–M200、M201–M250，各有同名图像字段、显式 Labels 与 Wavelengths；完整字段 shape/type、标签与映射见 [structure_audit.json](structure_audit.json)。五个文件是存储分块；官方未证明它们对应采集批次或生物群组，不能将留文件验证称为已知批次外推。

MAT 图像 ID 为零填充编号（如 M001），CSV 为 M1。映射严格要求 MAT 字段名符合 M 加三位数字、Labels 与字段集合相同；仅将数字编号去前导零，再验证与 CSV 的250个 ID 完整双射。此映射依据原始显式编号及官方配套数据关联，不依靠文件或行排列。波长均与 CSV 逐元素一致。

[原作者论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10823050/)的 Table 2 与 §4.3 支持204波段和已校正反射率图像；提取平均谱时另做过坏像素、尖峰及背景处理，故矩形 ROI 均值不必与 CSV 数值完全相等。论文没有说明本地 MAT 的逐像素掩膜编码，也未提供更细实体、采集日或批次对应关系。

全部250图像字段均为 MATLAB double，形状 `(height,width,204)`；两空间轴最小分别113、116，最大207、214，无须转置。各文件 Wavelengths 均为 `(1,204)`，范围400.00–998.04 nm。第五文件原始空间 ROI 确实较小，文件体积下降不是少了记录。

逐文件首例 M001、M051、M101、M151、M201 的选择性数值检查均为 float64、有限值，未发现全零像素；少量单波段零值不能据此认定为背景。样本最低值0–0.00944、最高值1.627–2.216；不依据数值范围擅自重标定。对应 CSV 谱形相关约0.9961–0.9986，非逐元素相同；具体值见机器审计。尚需由准备阶段对全部250立方体执行有限值与图像哈希检查，并核查预检重复谱组。

建议固定8×8×24：保留原始完整矩形 ROI，包括零值；不新增阈值分割。空间采用面积加权等大小网格平均，204个有序波长连续分成24个尽量等数量组（12组9波段、12组8波段），组内平均，同时保留同 ROI 的204维原始空间均值谱。保留原始坐标、权重与波组映射；归一化 ROI 坐标不能自动解释为不同样本之间完全对应的组织位置。
