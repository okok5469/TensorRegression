# 任务卡11：事前协议与执行边界

协议日期：2026-10-18（Asia/Shanghai）。本文件在任何任务卡11新科学输入生成前写入；源码、确切请求及环境在启动前另以 JSON/SHA256 封存。当前是预声明方案，实际运行数量以 FINAL_VALIDATION.json 为准，不能将此方案视为已完成实验。

## 唯一研究候选与基线

正式基线 v5.2-search-final。A0 为原全局 MSIC（alpha=1.5、gamma=1）；A1 仅增加 `log(max(log(n), e))*q*q/(2*n)`。这是经验候选，不声称标准有限样本公式或新一致性定理。q 是完整矩形支撑元素数，n 是该例实际训练行数，无自由参数。

每个完整输入只运行一次正式 Cold 全整数网格搜索，包括正式 adaptive 终态候选；两臂共享原始训练/测试数据、预处理、候选顺序、B、RSS、caps、q 上限及轨迹。模式内 MSIC、初始化、BCD、best-visited、Splicing 和 OLS 不变。各规则分别求首个分数 argmin，并用各自 q_best 计算正式 kappa=1 容忍带；全局 eligible 使用精确 `score<=min_score+T`，不添加浮点容差，按 `(q,score,s1+s2+s3)` 排序，全键相同保留原始顺序。A0 的索引、支撑、B、RSS 与正式输出必须一致，不一致立即停止。

## 历史预检

任务卡8/9的216个完整库均已见，只用于实现与风险检查，绝不并入新验证。重评分不改变 B/RSS 或补造缺失外测值，报告可信 PMSE 可用分母。发现程序错误必须先修复和重新验收；发现规则正确却严重破坏恢复时，按任务卡11.4允许提前终止并保留v5.2。不得失败后更换公式、系数或门槛。

## 新输入与阶段

沿用 Task8 的 DGP：dims=(32,20,25)，连续矩形支撑，sigma=1，n_test=500，test_batch_size=100；其余生成与求解参数逐字段继承原计划，并保存来源指纹。24场景为 n=(100,400)、SNR=(0.5,2,4)、shape=((4,3,5),(2,3,4))、rho=(0,0.6) 的笛卡尔积，每场景4个完全不同随机族，共96例。rho在三个模式取相同值。各场景各重复使用不同 train seed、独立 test seed，不把相同随机族跨场景算为独立重复。random_state=2026只用于既定求解器初始化，不替代数据生成种子。

Pilot单独使用新随机族，仅用于正确性和成本，不计入96例、不据其预测调规则。建议6例覆盖两样本量、弱强信号及n400两形状/两相关水平；确切请求在 Pilot plan 生成前封存。Pilot 和 validation 候选 seed 基数分别为1201810000、1601810000，逐cell加1000、逐重复加1，test=seed+50000000；实际使用前核对所有可取得历史seed/test_seed/split_seed及完整X/y指纹，任何冲突均停止，不擅自换种子。新输出间亦检查重复输入，保存B_true/支撑及测试流身份。

## 资源与停止规则

最多2个worker，每worker四种BLAS/OMP线程变量均为1。单case上限3600秒；正式96例共用28800秒墙钟，不因阶段或重启重置。Pilot同样单case3600秒，总预算7200秒。已有环境直接使用，不安装依赖、改ACL或扩展机器资源。

Pilot完成后，以各n组最慢完整case时间对48例外推，两组总和除2，乘1.5余量并加60秒：`1.5*(48*max(t_n100)+48*max(t_n400))/2+60`；要求不超过28800秒且每组最慢时间乘1.5不超过3600秒。该估计不保证未见case均完成，实际硬限仍有效。预算门禁失败不得减少重复、删困难场景或加预算；未完成96例不能推广。任何输入身份、源码、A0一致性、OLS或控制器失败停止依赖阶段，保存失败记录，默认保留v5.2。

## 评价分母与决策

只在24场景每场景4例完整、96请求身份一致后计算推广门槛；不使用可完成子集。总体每case等权，因设计平衡也等于24场景均值等权。n100、n400各48；强信号固定SNR=4，两样本量/两形状/两rho共32。Exact与q欠选按所有对应例报告，同时单列原caps下真形状可表示与真支撑进入池的子组；结构不可表示导致Exact=0不可归咎选择器。

| 指标 | 固定通过要求 | 分母/计算 |
|---|---|---|
| n100平均PMSE | A1/A0 ≤0.95 | 48例均值比 |
| 整体平均PMSE | A1/A0 ≤0.98 | 96例均值比 |
| n100 PMSE P95 | A1/A0 ≤1.05 | 各48例，NumPy线性插值分位数 |
| 最坏完整场景PMSE | A1/A0 ≤1.15 | 24个场景内各4例均值比的最大值，不是单case最大比 |
| n400平均PMSE | A1/A0 ≤1.03 | 48例均值比 |
| n400 Exact率差 | A1−A0 ≥−0.05 | 48配对；最多净损失2例 |
| 强信号q欠选率差 | A1−A0 ≤0.05 | 32配对；最多净增加1例 |
| 工程正确性 | 所有规定检查通过 | 独立门禁，不能由统计收益抵消 |

边界使用原浮点值和闭区间比较，不先四舍五入。PMSE必须正且有限；零分母、NaN、Inf、请求缺失/重复视为审计失败，不填补、不丢弃。改善/相同/恶化计数采用误差容差 `1e-12*max(1,abs(A0),abs(A1))`，仅用于描述计数，不放宽推广阈值。

同时报告均值、中位数、P95、配对差、单case最坏比、每SNR/rho/完整cell、REE、element F1、形状/q分布、欠选/过选和真支撑入池后的选中情况；逐改变case记录两臂索引、支撑、q、RSS、拟合项、原惩罚、FS项、argmin及容忍带。相同形状不同支撑的训练RSS排序不能由本次q修正解决。

不确定性事前固定：在各场景内成对重采样完整case，保持24场景及每场景4例权重，20000次bootstrap，分析随机seed=11011011，报告95%区间；该seed不生成科学输入。仅全部门槛通过且n100与总体PMSE均值比区间上界<1时，才认为均值收益有足够稳定证据供推荐；仍不宣称各场景或恢复非劣的统计证明。另报告少数最大改善case贡献，防止只凭极值均值宣传。

## 终版边界

通过时仅推荐隔离候选，正式替换需用户最终批准；不通过、预算不足或验证未完成时直接冻结v5.2-search-final和原MSIC。两种结果均结束本轮算法调整，不自动开启任务卡12、不再调alpha/gamma/容忍带、不依已见LEMON外测修改算法。下一阶段只交付数据适配性审查提纲，不下载或运行新真实数据。
