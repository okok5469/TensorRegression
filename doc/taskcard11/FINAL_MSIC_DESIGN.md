## 3. 容忍带、并列规则与配对重评分

对每个规则 r，先在保存的原候选顺序中找首个最小分数候选 `j_r`，令 `q_best,r=q(j_r)`。正式 `kappa=1`，精确带宽为：

\[
T_r=\kappa\sqrt{\max(q_{\mathrm{best},r},1)\max(\log(\max(n,2)),1)}.
\]

`bcd.py:85`—`:88` 对 `scale<=0` 返回 0，本卡固定为 1，不触发该分支。第 148—158 行以精确 `score <= min_score + T_r` 形成 eligible，再按 `(q, score, s1+s2+s3)` 的最小键选取；全部键仍相同时保留原候选先后顺序。没有新增 `isclose` 或随机 tie-break。fixed BCD 内的浮点接受容差不是全局选阶比较容差。

新规则必须独立求自己的最小分数、`q_best`、带宽和 eligible；不得套用原 A0 带宽。该带宽是确定性小模型优先规则，没有估计 CV 标准误，不能声称具有经典 one-standard-error 的统计保证。

A0/A1 每例共享一次完整正式 v5.2 搜索所得的候选 B、支撑、RSS、候选次序和 caps。A0 的分数、首个 argmin、eligible 和最终所选完整状态必须重现正式程序；单凭本文件的静态审计不能宣布数值重放通过，实际结果见本卡 `MSIC_RESCORING_AUDIT.md` 与最终验收。若 A0 不一致，应立即停止依赖实验。

## 4. 唯一候选与数学检查

唯一冻结规则是：

\[
\boxed{M_{\mathrm{FS}}=M_0+\frac{\ell_nq^2}{2n}}.
\]

不设可调系数，不改 n 的定义，不变更原惩罚、候选库或容忍带参数。对任务卡有效域 `n>0`、非空合法支撑、有限 RSS/B，附加项有定义、非负、随 q 严格增加且凸，没有零分母或额外奇点。它与原信息准则一样按无量纲复杂度计分；响应单位变化在未触发 `tiny` 截断时只给各候选原拟合项加共同常数，附加项不改变这一性质。未发现阻止该唯一规则进入工程预检的定义、量纲或机制错误。

它相对原线性 df 惩罚的大小恰为：

\[
\frac{\ell_nq^2/(2n)}{1.5q\ell_n}=\frac{q}{3n}.
\]

因此在原 `q<=.7n` 的合法域内，相对增加最多约 23.33% 的 df 惩罚；这是上界而非每例实际可达到的 q。它比历史 `alpha:1.5→2` 的统一 33.33% df 增幅温和，并随 q/n 调整强度，不能据此推断一定保留恢复。

在同一有限候选池中增加随 q 严格递增的附加项，会使最低分 argmin 的 q 不增：若新 argmin q 大于旧 argmin q，它既无原分数优势，又承受更大附加项，违反新最小性。但最终带内选择不同：argmin q 变化会缩小带宽，原来 eligible 的更小模型可能退出，故最终输出 q 仍可能上升；这不是修正实现错误的充分证据，必须记录该例的完整分数和带宽。

## 5. 文献支持的动机与不能转移的结论

Hurvich 与 Tsai（1989），*Regression and time series model selection in small samples*，Biometrika 76(2):297–307，提出回归与自回归模型 AIC 的偏差修正，尤其针对小样本及参数数目占样本量较高的情形；本次核实出版方摘要，只将其用于“有限样本、较高参数占比值得额外检查”的动机，不声称其推导了本卡公式。[出版方原文页面](https://academic.oup.com/biomet/article-abstract/76/2/297/265326)。

Chen 与 Chen（2008），*Extended Bayesian information criteria for model selection with large model spaces*，Biometrika 95(3):759–771，区分参数数目与模型空间复杂度，其 EBIC 含 `2 gamma log tau(S_j)`，并在指定条件下研究一致性；这支持将矩形模型空间计数与参数量作为不同维度理解，不能把 EBIC 的系数、定理或误差控制直接转移给本项目的 `ell_n` 加权 MSIC 或 MSIC-FS。[作者原论文稿](https://www.stat.ubc.ca/~jhchen/paper/Bio08.pdf)。

本卡附加项属于任务卡预先提出的经验性有限样本修正；`1/2` 系数、`q^2/n` 形式和 `ell_n` 权重没有在上述原始论文中得到针对当前 Tensor-ABESS 的推导。本卡不称其为标准 AICc、无偏风险估计、已证一致准则或新的理论结果，也不以文献替代预注册预测/恢复门槛。

## 6. 机制边界与决策约束

相同形状的两候选有相同 q、组合惩罚及 FS 项，其分数差仍仅由拟合项决定，无法修复任务卡9已见的低训练 RSS、高测试 PMSE 排序反转。相同 q、不同形状的 FS 增量也相等，二者相对分数排序不变；最终集合变化仍可能改变被选形状，应按实际选中结果解释。

附加项不使用设计矩阵条件数、相关结构、支撑搜索自由度或真模型遗漏情况，因此不是 OLS 方差的精确估计；q 也不随矩阵秩自动调整。弱信号改善、强信号欠选、尾部恶化和可表示但真支撑被放弃都须报告；不允许为了获益换公式、调系数、扩大 caps、以 Ridge 替 OLS 或修改历史门槛。

历史池只作工程及风险预检。若预检没有阻塞，是否值得改变正式算法仍由本卡唯一前瞻验证的完整门槛决定；未完成、正确性失败或收益不足都保留正式 v5.2 原 MSIC，并结束本轮算法调整。所有实际运行数、未运行阶段及最终判断以本卡 `FINAL_VALIDATION.json` 与 `FINAL_ALGORITHM_DECISION.md` 为准。
