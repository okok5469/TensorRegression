# 下一阶段真实数据适配性审查提纲

2026-10-18（北京时间）。本文件是后续研究的审查框架，不代表已经寻找、下载、筛选或重新运行任何数据集；这些操作在本卡均为 `NOT_RUN`。算法版本以任务卡11终版决策为准，不因某个已见实证排名不佳重新打开 MSIC、BCD、Splicing 或 caps 调参。

## 1. 入选原则与记录单位

每个候选数据集先形成一份有来源和版本的审查记录：科学问题、分析人群、连续响应、三阶张量定义、独立样本单位、可获得性、许可/使用约束、处理方案、验证方案及结论依据。选择依据是科学价值、结构匹配、数据质量、可复现性和公平比较的可行性，不以 Tensor-ABESS 是否排名第一筛选；相同原则允许保留“不占优”的研究结果。

审查状态采用 `SUPPORTED / UNSUPPORTED / UNKNOWN`，每项附实际证据位置。未知信息保持未知，不通过改写响应、重复换划分或挑结果最好的子人群补成支持。缺乏关键字段时先补齐来源，不能把数据加工成一个形式上的三阶数组就认定结构适配。

## 2. 科学问题与响应

| 检查 | 必须保留的证据 | 对研究的影响 |
|---|---|---|
| 连续响应有清晰意义 | 测量定义、单位、量表范围、采集时点、缺失原因、可靠性来源 | 明确究竟预测什么，以及预期用途；不按算法表现事后换响应。 |
| 张量与响应有合理联系 | 原研究设计、可信先验或独立文献；张量和响应时间关系 | 区分科学假设与事后相关，不将关联宣称为因果。 |
| 张量有望提供协变量之外的信息 | 预定协变量的科学依据、可核验的简单基线或训练内探索 | 重点回答增量价值，不能只胜过无信息均值即宣布有实际贡献。 |
| 分析人群可解释 | 纳入/排除规则、最终人数、可追踪受试者 ID | 防止模型结果决定纳排，避免目标人群定义漂移。 |

## 3. 张量结构与矩形支撑假设

逐一写明三个模式的含义、单位、排序、分辨率和测量来源，例如它们是否为真实传感器、时间/频率或其他实验维度；必须解释这些轴为何有结构意义，不为套用方法任意拆分向量维度。说明模式内切片是否具有一致含义，缺失或重采样如何处理，三模式尺寸如何事先确定。

再判断是否有科学理由支持少数模式切片共同决定响应，即系数可以近似位于 `S1×S2×S3`。矩形内允许系数为零并不等于任意稀疏结构都与该假设同等匹配；若信号更可能沿不规则元素、低秩因子或不同位置分散，记录该失配及适当对照，不在已见外测结果后改造张量来制造适配。

记录每个训练折的样本数、模式尺寸、原逐模 caps 和总 q 上限，区分科学上希望表示的模式范围是否落在算法实际可选域。真实数据没有已知真支撑，不能把选中小模型、稳定性或可解释切片当作 Exact 恢复证据。

## 4. 样本独立性、信号与质量

- 明确独立单位是受试者、家庭、站点还是时间段；重复测量、亲属关系、重复扫描和同人多片段不得被当作独立受试者随机拆入训练和测试。
- 保留批次/站点/设备、年龄性别及其他事先指定协变量的定义，检查响应分布、缺失模式、量纲和异常值来源；异常值处理规则不能由外测损失决定。
- 样本量讨论基于有效独立单位和预定训练比例，报告每折真实 n；不得把重复交叉验证次数乘入独立样本量，也不擅自将某个“有效 n”塞回冻结 MSIC。
- 使用仅协变量线性模型、合理的向量线性或 Ridge 等预声明基线检验信息量；超参数、预处理和特征筛选使用训练内数据，不能用外测试表现挑数据集再将同一外测称为独立证据。
- 先评估信号可靠性、响应噪声与可复现增量，再解释算法差异；多个合理张量模型均无增量时，应保留“当前特征信息有限”的解释，而非自动判定优化器故障。

## 5. 公平、无泄漏的评价协议

在正式比较前冻结纳排、响应变换、张量构造、协变量、数据划分、所有模型、调参预算、主要指标和不确定性方法。按数据独立单位分组划分；如目标是跨站点或未来泛化，预先匹配对应验证单位。外部验证不能与训练内选参数或数据选择混用。

协变量残差化、标准化、缺失处理、降维、特征筛选及支撑搜索都在各内训练折重新拟合，内验证/外测试只应用训练得到的参数。不同模型使用同一受试者集合、响应、外层划分和共同评价原则，记录无法比较的情形而不偷偷改变分母。

主要报告完整 OOF 或独立外测试的 RMSE/MSE、R²和相对仅协变量基线的配对增量；如采用重复外层 CV，先在每次完整 OOF 上计算指标，不能无说明地平均折内 R²，也不能把同一人的多次预测当作独立样本。按独立受试者或既定簇报告配对不确定性，呈现均值、尾部、预定亚组和所有恶化案例。

同时保存训练误差、q/形状分布、所选支撑、版本指纹、运行成本与预测恢复核验；这些用于解释机制，训练拟合或较小 q 不替代泛化证据。明确区分：适配性探索使用过的数据、内部调参数据和尚未用于决策的独立验证数据。

## 7. 审查结论格式与进入下一阶段条件

每个数据集给出一个可复核结论：`可进入预注册比较 / 证据待补 / 当前结构或科学问题不适配`，同时写出最关键的事实、未解决问题和证据路径。入选应满足科学问题明确、结构有依据、独立单位可追踪、来源可合法获取、处理可重现及公平验证可执行；不适配时保留原因，不换评价指标把模型包装成最优。

进入正式研究后允许报告三类结果：Tensor-ABESS 有明确增量、与合理基线相当、或不占优；三者均可为结构假设与适用条件提供证据。本卡的算法冻结是下一阶段的起点，数据适配审查不构成继续调整算法的授权。
