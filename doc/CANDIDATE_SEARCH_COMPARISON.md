# 候选搜索机制配对比较（任务卡3）

## 实验定义与来源

生产算法仍为v5.1-bcd-fix，本研究使用隔离v5.2源码，fixed BCD与v5.1相同；全部组使用原MSIC：mode alpha=1、global alpha=1.5、gamma=1、one_se_scale=1。原Group-BESS、GLasso/Lasso/Oracle和DGP未改。

A0=旧caps/旧网格；A1=候选级caps/旧网格；A2=旧caps/完整整数；A3=候选级caps/完整整数；A4=候选级caps/预定训练top3附近±1一次扩展。q≤floor(.7n)、候选预算2000，超限停止，没有静默预算截断。完整仅指给定训练caps内的合法整数形状，不穷举所有位置或所有维度合法形状。rawcaps仍为训练GLasso大小和sqrt(n)/2启发式。

历史27与任务卡2完全相同，独立新增开发90（9场景×10重复）事先冻结，另有独立确认90计划；测试集只评价，不生成候选或选初始化。每个数据集所有组严格使用同一X/y/B_true及500条独立测试流。历史用于解释机制，开发用于门槛判断，独立确认未用于反复挑参数。n100/200/400×SNR0.5/2/4，dims32/20/25、真形状4/3/5、rho=.3、sigma=1；训练入口c=3、k_max=1、max_cycles=6，不能混称所有公共默认设置。

本报告历史27和开发90均已完整，严格summarize/analyse/contrasts/numerics四项核验通过；以下依据完整队列，未使用部分结果或独立确认挑参。最终数据目录为outputs_candidate_search_study/historical_final、development_final；旧historical/development标STOPPED，不混入。

## 成本与正确性口径

观察耗时受固定组顺序共享显式候选cache影响；独立成本估计=本组elapsed+命中缓存fixed的原fit_seconds，不是独立冷启动实测。A3历史估计497.71秒，约A0的3.78倍；A4约175.63秒，但候选减少并不自动保证相同结果。cache键显式绑定训练字节/shape/dtype及solver配置，不混训练数据；所有拟合状态保留副本。

历史26,782个fixed候选记录通过accepted非增/minvisited/bestpointer/容量/RSS=2nloss一致性检查，包含缓存重复，不计作独立拟合数。135个最终所选设计矩阵均满秩，最大条件数13.2388，最大RSS重算相对差4.912e−16，无数值异常；条件数审计只覆盖所选模型。CSV与JSON详见对应目录mechanism_*、factorial_*、coarse_search_diagnostics.csv、selected_model_numerics.csv。

变q adaptive阶段按mode MSIC选阶，减小q允许RSS上升，固定q accepted BCD仍须RSS非增；验证器分类修复与真实反例见taskcard3_validator_failure.json，算法及数值容差未改变。
