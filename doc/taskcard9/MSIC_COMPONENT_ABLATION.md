# MSIC组成与冻结Cold库的2×2消融

216个既有Task8 Cold库固定后，只改变全局alpha和容忍带scale，得到864次选择；候选B、支撑、OLS、caps、网格、模式内规则与搜索路径均未重跑。127872个候选分数与实际冻结源码计算逐项精确相同，A0/A3的原最小值、eligible集合和最终选择全部重现。这是已见数据上的机制诊断，不能重新标为独立确认或用于发布新规则。

## 实际源码公式、默认值与次序

核对[实际sic.py](../../src/tensor_abess/tensor/sic.py)及[实际bcd.py](../../src/tensor_abess/tensor/bcd.py)，生产与冻结v5.2均32文件字节一致。全局分数为：

`MSIC = n log(max(RSS/n, tiny)) + alpha*q*ell + gamma*ell*Σlog C(p_m,s_m)`，`ell=log(max(log(n),e))`，`tiny=np.finfo(float).tiny`。组合数用gammaln计算。

底层`compute_tensor_msic_from_rss`通用helper默认alpha=1，但正式adaptive入口显式全局alpha=1.5、gamma=1；模式内alpha=1、gamma=1。本轮只改全局重评分的alpha，不能据helper默认值误报正式参数。

候选次序为adaptive终态在先，再按(s1,s2,s3)字典序遍历满足原caps及q≤floor(.7n)的完整网格。先按分数取稳定的首个argmin，其q记为q_min；容忍带 `tol=scale*sqrt(max(q_min,1)*max(log(max(n,2)),1))`（scale≤0时tol=0）；eligible精确比较 `score<=min_score+tol`，最终按 `(q,score,s1+s2+s3)`取最小，键仍同分时沿用原候选顺序。没有额外isclose容差。fixed BCD内的64eps/finite/cycle保护不属于最终选阶tie规则。

该one-SE风格带宽由q_min与n构造，未使用CV误差标准差，不具经典交叉验证one-standard-error统计解释。scale0会取消带宽，通常允许从较小模型回到MSIC argmin；并不意味着更强收缩。

| 方案 | 全局alpha | scale | gamma |
|---|---:|---:|---:|
| A0 | 1.5 | 1 | 1 |
| A1 | 2.0 | 1 | 1 |
| A2 | 1.5 | 0 | 1 |
| A3 | 2.0 | 0 | 1 |

固定候选上提高alpha只增加 `0.5*q*ell`；RSS项、组合惩罚均不变。不同最终模型间的分数差则同时含RSS、q与形状的差异，不能将它们误作同一B上的惩罚效应。scale不改变任何候选分数，仅改变eligible与最终选择。每个方案的最低分/最终候选及拟合项、df惩罚、组合惩罚，以及A0最终候选在该规则下的项，完整见[four_rule_decomposition.json](pool_msic/four_rule_decomposition.json)。

下表的delta均来自同一组完整数据和相同Cold库：alpha效应=A1−A0；移除带宽效应=A2−A0；交互=A3−A1−A2+A0。它们是在既定有限候选池上的干预结果，不代表重新按alpha2搜索的算法效应。

|---|---:|---:|---:|
| n100欠选率 | +0.361111 | −0.250000 | +0.027778 |

| n400欠选率 | +0.055556 | −0.097222 | 0.000000 |

提高alpha在本组平均收缩；取消容忍带通常扩大模型，二者相互抵消且存在离散选择交互。加罚不保证容忍带后的最终q逐例下降：development任务36的A0→A1为q2→3（argmin q24→3），confirmation任务49为q1→2（argmin q45→2）；带宽随argmin q变化使两个最终选择反向。本216例最低分argmin的q没有增加，但最终带宽选择有这2例反向，二者必须区分。故任务8的A3平均改善与欠选变化不能归结为“去掉容忍带使模型更小”，也不能据A3一个对角比较认定单独提高惩罚足够。完整q、Exact、F1、REE因素表见[four_rule_factorial.csv](pool_msic/four_rule_factorial.csv)。

## 结论与复现

本轮把A3的两个因素分开：加强惩罚驱动收缩和欠选，移除带宽反向推动更大模型，且有相互作用。预测方向依赖场景；更重要的是，同形状异支撑的低RSS高PMSE反例无法靠q/形状惩罚排序解决，见[候选池报告](CANDIDATE_SELECTION_GAP.md)。优先设计训练内CV/稳定性诊断，保留小样本复杂度修正作为次级对照，不推广A1或A3。

四个线程变量设1后，以原`.venv/Scripts/python.exe -B -m research.taskcard9.pool_msic rescore`复现；先完成本轮inventory及12例replay，未来复算各命令共同加`--output doc/taskcard9/reproduction_new`，输出独占创建、现有结果禁止覆盖。测试命令为`.venv/Scripts/python.exe -B -m unittest research.taskcard9.test_pool_msic`，4项先红后绿。正式源码、历史候选库和原任务8门禁不变；[机器汇总](pool_msic/four_rule_summary.json)、[全资产身份审计](pool_msic/identity_audit.json)与[冻结协议](PROTOCOL.json)共同限定本报告的结论范围。
