# 双规则实证验证

LEMON 完整 15 折比较已完成。FS 相比原 MSIC 明显降低本次验证的 OOF 误差，但两个版本均弱于仅协变量及全部既有比较模型，尚未显示稳定的 EEG 增量预测价值。HCP-YA、NKI-RS 为 `NOT_RUN`，输入配置为 `NOT_PROVIDED`。算法最终建议保持 `PENDING_CLUSTER_RESULTS`；本报告不批准 FS 发布，也不据实证结果继续调整 MSIC。

## 数据、协议与可比性

真实分析数据为 145 人、天然 `61×16×5` EEG 张量，响应是 `log(TMT_5)`，协变量设计 8 列。原始张量 146 人，按原审计清单形成 145 人分析集；本任务没有重新生成 EEG、增加排除或改变样本。沿用原 3×5 外层划分，每折训练 116 人、测试 29 人；受试者顺序和全部训练预处理参数与历史 v5 / 正式 v5.2 保存值逐项相等。

P0 Gate 通过、集群包先交付、主线发布冻结协议后才启动本次唯一完整运行。每折一次原 v5.2 搜索，original / FS 共用完整候选池；两者都只使用训练信息选阶。先保存候选池、选阶、系数、训练预处理和划分，再为每臂每折各预测一次外测。全程未重跑、未修改冻结源码/配置、未改变公式或容忍带。

旧输入的 8 项文件指纹、原配置、历史结果与训练预处理通过核验。保留 Covariates Only、Vector Lasso、Tensor-GLasso、Ridge 共 1,740 条历史 OOF 预测，没有重跑 baseline 调参或拟合。两规则各新增 435 条 OOF，合计保存 2,610 条全模型预测。每个模型先按每次重复的完整 145 人 OOF 计算指标，再对 3 次重复取平均，不以平均外折 RMSE 替代整体 OOF RMSE。

## 选阶与训练误差

| 指标（15 折） | 原 MSIC | FS |
|---|---:|---:|
| q 均值 | 37.467 | 3.533 |
| q 中位数 | 24 | 2 |
| q 最小–最大 | 1–80 | 1–24 |
| q > 训练人数一半的折数 | 7/15 | 0/15 |
| 平均训练 RMSE | 0.192871 | 0.271507 |

FS 改变 10/15 折选择：q 下降 7 折、上升 3 折、相同 5 折。7 个原 q 为 60、64 或 80 的折全部转为 q=1、2 或 3，且外测 RMSE 全部改善；训练误差增大而外测误差降低，与减轻大模型过拟合相符。FS 使用自己的 argmin 与容忍带，因此正惩罚并不保证最终 q 在每折单调下降；这解释了另 3 折 q 增加，程序没有强行限制或后处理。

此处没有真支撑标签，不能把 q 下降等同于支撑恢复更准确，也不能仅据 q 增加或下降断言过选/欠选。高维 EEG 表征、有限样本、矩形支撑假设及响应可预测性可能共同限制增量价值；本次消融不能单独识别这些原因，不据此改算法。

## 证据强度与未运行数据集

这是已见 LEMON 数据上的研究性消融，不是新的盲法外部确认。3 次重复使用同一批 145 人，15 折之间也存在训练集重叠；本报告不把它们当独立样本给出显著性或虚假精度。全部描述性结果按预定协议保留，不以实证结果选择公式、候选池、基线或数据子集。新的集群模拟确认尚未回传，最终科学建议仍为 `PENDING_CLUSTER_RESULTS`。

HCP-YA 和 NKI-RS 在本仓库 `empirical_analysis`、`research`、`scripts` 审计范围未发现实际数据/响应/协变量/划分及历史 baseline 流程；不声称检查了用户计算机全部目录。两者分别交付独立 `NOT_PROVIDED` 配置及通用契约，执行状态为 `NOT_RUN`，未拟合、下载或联系外部人员。

契约覆盖天然三阶张量、连续响应声明、协变量、唯一 ID、每次重复完整外折覆盖、可配置组隔离、训练预处理 adapter、历史 baseline 输入/预处理/源码/配置身份。通用运行器目前实现 RMSE/R²，尚不能证明与未提供的 HCP/NKI 原评价协议一致；若原指标不同，须在相应协议冻结前补齐评价适配与检查，不能运行后替换原评价。输入与预处理的补齐也不自动授权拟合，仍需 P0 与各数据集冻结协议。契约与双平台命令见 [README](../../research/taskcard12/empirical_configs/README.md)。
