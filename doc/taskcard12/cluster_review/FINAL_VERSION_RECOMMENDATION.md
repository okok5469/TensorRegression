## 6. LEMON与证据边界

LEMON 已完成相同145人、3×5原外折、原训练预处理及每折共享池的比较，并已独立验收。原/FS/仅协变量的平均 OOF RMSE 分别为 **0.504581 / 0.359627 / 0.317485**，R² 为 **−0.597008 / 0.183142 / 0.367900**。FS 相比原规则的 RMSE 改善28.73%，但仍比仅协变量高13.27%，也弱于既有 Ridge、Lasso、GLasso。外折改善/相同/恶化为9/5/1；q均值37.467→3.533。

因此 LEMON 支持“减轻原选阶的预测代价”，不支持“Tensor-ABESS 已有稳定 EEG 增量预测优势”，也不能弥补集群 n200 恢复门槛失败。LEMON 是已见数据上的研究性消融，同一145人的3次重复不是3个独立数据集。HCP-YA/NKI-RS仍为 `NOT_RUN`，没有补造实证成绩。完整数值与失败外折见 [实证报告](../EMPIRICAL_DUAL_MSIC_REPORT.md)。

模拟区间采用冻结的20,000次场景内**成对**重采样，seed=12121212，保持既定权重；20,000次 bootstrap 不等于20,000次新科学重复。主场景各10例、压力30例仍有限，区间只反映当前固定设计，不构成对所有 n、信噪比、相关结构或真实数据的普遍结论。恢复门槛失败和宽区间均如实保留，不以新增阈值、事后子组或重跑改变判断。
