# 冻结结果图的证据与导出约定

本组图为方法章/模拟章的可复用草稿材料，只呈现已核验的正式Tensor-ABESS v5.2与已知真支撑Oracle；新增可靠Lasso/Group Lasso的完整比较尚未验收。Oracle不可部署，Exact=1来自给定真支撑，不能解释为估计器恢复能力或所有有限样本估计器的风险下界。历史旧基线不作为本组图的可靠主对照。

绘图后端明确为Python，偏好存本任务目录；原始结果和身份映射均只读。主输入为已生成的10配置历史汇总、700标签输入映射及旧计划；另从原冻结raw逐任务PMSE/Exact独立去重复算均值、样本SD与成功数，验证汇总对应关系。没有新增拟合或输入重建。

数据边界：完整保留600套唯一输入与10种配置。基准合并scenario0、3与6/9/12去重后的150套，其余9种各50。四条曲线共享同一基准估计，不将重复出现的基准点当成额外独立证据。仅按明确授权的两方法展示，未删除两方法的任何重复；20个旧基线汇总单元不进入可靠主比较图。

四图统一为定量网格、两互补面板：a建立含噪预测风险的量级及不确定性，b检验预测变化是否伴随真实支撑恢复；后者不只是再画一个同义预测指标。

| 图 | 科学问题与有限结论 | a的独特作用 | b的独特作用 |
|---|---|---|---|
| 样本量 | 样本增加是否同时改善预测与选择？小样本失败和n400恢复跃升均需保留 | PMSE均值及95% t区间 | Exact及Wilson95%，并由图注交代n100 caps限制 |
| 信噪比 | 弱信号的预测与选择代价是否一致？绝对PMSE与SNR本身都改变，不作归一化风险胜出推断 | 含噪风险量级 | 弱信号Exact为零及强信号恢复提高 |
| 张量维度 | 维度增大时预测与真位置恢复是否同步？不作通用维度标度定律 | 预测风险及较宽区间 | 大维度真实支撑恢复的降低 |
| 相关性 | 较低预测误差是否意味着较好真支撑恢复？两者需分别判断 | 相关设置下的预测风险 | 强相关下Exact仍低，避免把替代坐标视作真恢复 |

统计约定：PMSE中心为各配置唯一完整输入的算术均值，样本SD采用ddof=1，区间为t_(R−1,0.975)×SD/√R；Exact为三轴集合同时正确，率区间为双侧Wilson95%。重复单位为生成训练/测试输入，不是500个测试点。图中不作假设检验、p值、胜出计数或多重检验。PMSE面板与Exact面板刻画不同量，二者纵轴不要求相同；四图PMSE纵轴独立依数据区间设置并在图注说明。方法位置轻微水平错开，仅为避免区间重叠。

导出约定：183mm宽、约82mm高，正文/刻度/图例7pt，粗体小写面板字母7pt；蓝色圆点实线为Tensor-ABESS，灰色方点虚线为Oracle。PDF保留可编辑TrueType文本，PNG 600dpi；源CSV与中文图注独立保存。无照片、图像增强或外部模板，未使用AI图像。alignment需在最终draw后测量，默认1.5pt；随后运行source、PDF字形和collision检查并逐图逐面板可见检查，FAIL必须修正。
