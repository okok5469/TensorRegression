## 已确认的原实现问题

Vector Lasso在 `numerical_simulation/methods.py` 的lambda外循环内创建beta_warm，随后把前一验证折解传入下一折；后一折验证响应可能已用于前一折训练。有限500步ISTA且只检查系数改变量，无法证明影响CV选择的全部拟合充分求解。历史 `known_s_cluster/run.py` 对两基线记录 `diagnostics_available=false`，没有逐拟合KKT/原始—对偶证书；因此两种主对照均需600唯一输入统一更新，不能以pilot结果相近免除。

Group Lasso的原CV本身冷启动，没有上述跨折beta污染；其全训练预筛、前轴支撑和lambda网格仍进入局部CV设计，不能称严格嵌套全流程。修复保留无权重组目标、1→2→3初始化与外层更新、非空回退、最终矩形OLS、稳定集合或6轮停止，并不把它改造成另一个发表算法。该结构对照是本项目既有流程，未冒称文献方法。

两方法均无额外截距/中心化/标准化；Lasso不做post-Lasso OLS。lambda网格、五折划分、验证SSE和大lambda优先并列规则维持原定义。ABESS正式内部500步初始化保持冻结，不受新参考求解精度标准修改。

隔离源为 `research/taskcard18/solvers.py`、`baselines.py`；各CV折独立持有状态，只在同折相邻lambda复用；最终全训练另拟合。保存每个候选与最终拟合的样本数、目标、对偶可行性、KKT、gap、迭代、警告、停止、到限及来源哈希。失败异常保留截至失败的全部诊断路径。任何必要候选未过双证书即拒绝其CV分数，不产生新测试评价。
