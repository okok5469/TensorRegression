## 比较及信息边界

正式 `v5.2-search-final + 原MSIC` 和 Oracle 保存结果经身份核验后复用；Vector Lasso 的跨折状态及两基线全部凸拟合缺失证书，决定二者在600完整唯一输入统一补算，分别使用 `vector_lasso_cv_isolated_v1`、`sequential_tensor_glasso_certified_v1`。14历史标签保留；论文主分析按10配置，基准150，其余各50，不将共享标签当额外重复。

主指标为独立500点含噪PMSE；同时报告signal MSE、非平方REE、实际元素支撑、声明模式支撑、投影差异、Exact和矩形容量。Oracle仅为给定真支撑的诊断参照。运行时间仅描述本实现成本，不推导跨环境加速比。对照变强不触发ABESS或DGP更改。

## 固定训练诊断pilot

canonical scenario `[0,1,2,4,5,7,8,10,11,13]` 各replicate0、1，共20套；先校验其10配置身份。该阶段只读取训练数据/数值诊断，不生成新增方法测试成绩。冻结生成器、原seed/test_seed、test_batch_size100不可变。

新旧输入优先逐字节比对原四指纹；若本机BLAS使哈希不等，不改写旧指纹，不声称逐字节相同。进一步核对保存B_true、train_noise、真实支撑，以及历史Oracle系数的训练RSS/独立测试PMSE（rtol=1e-10,atol=1e-10），明确可验证范围；任何实质不一致阻塞配对，不以近似新生成器替代。

## 固定统计流程

无截距、无额外中心化或标准化；Lasso目标RSS/(2n)+lambda*L1，Group目标RSS/(2n)+lambda*sum(group L2)，无组权重。n为当前拟合训练子集样本数。

20点降序lambda网格，完整当前训练设计的lambda_max至0.01lambda_max；五折为连续索引array_split，验证SSE相加，精确并列保留先遇到的较大lambda。每折状态仅来自本折训练，可沿相邻lambda复用，最终全训练独立拟合；Lasso保留L1系数，无OLS重拟合。完整训练构造网格须声明；不扩展网格，不据边界比例或测试排名改变规则。

Tensor-GLasso保留全训练边际预筛、1→2→3顺序初始化和局部CV、初始化最高边际非空回退、外层全位置逐模更新、空选择保留上一轮该轴支撑、每轮矩形OLS、集合稳定或6轮停止。完整训练预筛和其他轴支撑进入局部设计，不称全流程严格嵌套CV。此基线没有ABESS caps约束。

## 数值证书及有限策略

主Lasso使用既有sklearn1.5.2坐标下降，显式fit_intercept=False、selection=cyclic。Group Lasso使用隔离加速近端求解。正lambda每个内折候选及最终拟合同时满足最大KKT/lambda≤1e-4和原始—对偶gap/max(y'y/(2n),1e-12)≤1e-6；对偶通过残差缩放至可行。真实非零用于KKT，支撑评价1e-8阈值不得用于掩盖KKT。

预算固定为2000、10000、50000迭代三档，容差不变，达到证书立即停止；lambda0用lstsq及梯度验证，零响应/零设计可验证零解。保存目标、对偶可行性、gap、KKT、迭代、停止原因、到限与异常。明显负gap不得截断隐藏。独立小规模求解器比较目标和拟合值：Lasso拆正负L-BFGS-B，Group Lasso光滑凸对偶SLSQP。独立路径未被验证前不作为自动备用；至多一条等价备用路径可在训练pilot诊断后唯一一次修订冻结。未达证书不产生正式测试评价。

## 指标与统计冻结

元素支撑主阈值1e-8；1e-10/1e-6仅敏感性，旧矩形包络指标名为legacy。模式声明支撑和实际元素投影分列。无发现FDR=0、Recall/F1=0、Precision=NA并报告valid_n；Exact为三轴集合同时一致。各配置均值、样本SD(ddof1)、有效/失败分母；同完整unique_input_id配对PMSE差A−B、MCSE=s_d/sqrt(R)、t均值95%区间(df=R−1)；Exact用Wilson95%。不池化600/700求IID显著性，不以获胜次数为科学门槛。偏斜只用中位/IQR补充，本轮不增加择优bootstrap。
